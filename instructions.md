# Project Overview

You are building an application that renders Videos and Playlists from a users YouTube account as Files and Folders.

# Core Functionality

1. Authentication

   - The user should be able to login through Google, so that the application can fetch their video and playlist data

2. Folder views

   - The user should be able to create folder views, which can display folders in window panes
   - The user should be able to drag and drop "files" between the different Folder views
